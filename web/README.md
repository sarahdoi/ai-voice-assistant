# Sarjy frontend

Reserved for a small Next.js frontend, built after the backend.

```text
app/              Page and layout
app/api/token/    Server-side LiveKit token endpoint
components/       Talk button, status, transcript, memory panel
lib/              Connection helpers
public/           Static assets
```

Use the LiveKit React SDK for audio transport. Keep the API secret server-side.
Reference: https://github.com/livekit-examples/agent-starter-react
